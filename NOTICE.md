# Source provenance and notices

## Supplied Python implementation

`legacy/rta_original.py` is an unchanged copy of the user-supplied `rta(1).py`.
Its original notice reads:

> Copyright (C) 2024 Universidad Politécnica de Madrid

The actual source retains the original accented spelling and complete header.
The new package preserves the main construction API through a separately written
adapter and records intentional differences in `docs/MIGRATION.md`.

## Functional reference

The functional reference is the user-supplied `guide-4.pdf`, **RTA User's Guide**,
by Juan A. de la Puente, Universidad Politécnica de Madrid. The original Ada
implementation and its sources were not supplied or copied. The PDF is not
redistributed inside this project. `examples/guide_sample.tsf` transcribes the
worked input example for verification.
